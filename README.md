# Quiz-em-C
Trabalho da faculdade onde precisamos criar um quiz em C utilizando implementações de funcões.

O quiz consiste em um menu com interações como, jogar, criar perguntas, listar perguntas, estatisticas, e sair do jogo.

# Como funciona?

O usuario primeiramente precisa inserir as perguntas com as alternativas e a alternativa correta, assim que ele inserir ele conseguira jogar.

Em seguida ele inicia o jogo, o programa inicia o jogo, mostrando as perguntas que o usuario inseriu, a cada pergunta que o acerta o programa atualiza o placar e a porcentagem de acertos.

Chame seus amigos para jogar o quiz juntos, se divirtam!

Utilizei a linguagem de programação C para estar criando este quiz.
